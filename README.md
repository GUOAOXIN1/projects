# PowerPoint build smoke test

This repository contains a generic, synthetic test of a PowerPoint editing and PDF-rendering pipeline on GitHub Actions.

The test creates a two-slide dummy presentation, reopens and edits it, verifies image preservation and unchanged-slide XML, renders the result with LibreOffice, and exports a PDF plus PNG previews and a machine-readable verification report.

## Privacy boundary

Only dummy content generated by the test is used. No course presentations, uploaded documents, personal details, credentials, or confidential material are included or requested. This test does not import external presentations.

The workflow uses read-only repository permissions. It does not push generated output back to the repository or deploy a website. Build outputs are available as a short-lived GitHub Actions artifact.

## Run

The smoke test runs when its workflow or script is updated on the default branch, or when started manually from the Actions tab. A passing result verifies the tested execution pipeline only; it is not validation of any separate presentation.
